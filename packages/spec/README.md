# @umlay/spec

Umlay DSL の公式仕様。BNF 文法、予約語一覧、正規IR の JSON Schema を提供する。

## 内容

- `src/grammar.md` — 人間可読な文法仕様 (予約語含む)
- `src/ir.schema.json` — 正規IR の JSON Schema (Draft 2020-12)
- `src/index.ts` — バージョン情報と構造エクスポート
